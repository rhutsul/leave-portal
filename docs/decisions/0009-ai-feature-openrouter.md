# 0009. AI-функція зрізу 4 «Calendar assistant»: AI SDK + OpenRouter (безкоштовні моделі) + zod

- Статус: прийнято (нові залежності погоджено людиною 2026-11-15)
- Дата: 2026-11-15
- AC: AC-ASSIST-01…AC-ASSIST-11 (`requirements/05-calendar-assistant.md`, `openspec/specs/calendar-assistant/`)
- Джерело: заготовка ADR із набору курсу
  https://github.com/koldovsky/2026-quitcode-10-ai-features-hw/tree/main/materials/ai-feature
  (`docs/decisions/NNNN-ai-feature-openrouter.md`), «Контекст» переписано під наш зріз 4

## Контекст

Зріз 4 додає помічника шкільного календаря (`requirements/05-calendar-assistant.md`). Адміністратор вставляє текст
шкільного календаря до 2000 знаків (AC-ASSIST-10), помічник пропонує закриття — цілі дні (дати початку й кінця) або
скорочений день (дата й година закриття), — адміністратор перевіряє, виправляє чи прибирає пропозиції й зберігає решту
через наявну дію закриття зрізу 3 (`addClosure` у `src/app/(app)/calendar/actions.ts`, правила вимоги 04,
AC-ASSIST-02…04). Помічник нічого не зберігає сам. Текст не про календар — відмова (AC-ASSIST-06), бракує даних —
«needs more details» (AC-ASSIST-05), інструкції в тексті — лише текст (AC-ASSIST-07). Користуватися може лише
адміністратор (AC-ASSIST-11). Якість — 10 golden cases PM, поріг 8 з 10, GC-08…GC-10 — завжди.

Обмеження:

- Next.js 16.4 на Vercel Hobby: функція працює до 300 с; Server Action приймає тіло до 1 МБ за замовчуванням.
- Помічник відповідає за 30 с, інакше він недоступний (AC-ASSIST-09, Assumptions вимоги 05); те саме повідомлення —
  коли вичерпано денний ліміт.
- Модель — безкоштовна через OpenRouter, ключ — власний у кожного розробника. Ліміт безкоштовних моделей —
  20 запитів/хв і 50/день на акаунт (1000/день після одноразової покупки ≥ 10 кредитів); додаткові ключі
  ліміту не збільшують. Безкоштовні моделі з'являються й зникають.
- Безкоштовні ендпоінти можуть зберігати й використовувати запити для навчання → лише синтетичні дані (вимога 05
  теж: тексти в тестах синтетичні, без справжніх документів школи).
- Відповідь моделі недетермінована, а CI має бути без мережі й без секретів.
- Завантаження файлів (PDF, Word, фото) — поза межами зрізу 4 (Out of scope вимоги 05): лише вставлений текст.

## Рішення

- Нові залежності (точні версії): `ai@7.0.162`, `@openrouter/ai-sdk-provider@3.1.0`, `zod@4.6.7`, `server-only@0.0.1`.
- Виклик — `generateText` + `Output.object({ schema })` (AI SDK 7; `generateObject` застарілий).
  Схема zod (`src/lib/ai/schema.ts`) має стан `status: ok | needs_info | refused`; «невідоме» = `null`.
- Чиста функція `proposeDraft(input, model)` (`src/lib/ai/draft.ts`) отримує модель параметром;
  ключ читає лише `src/lib/ai/openrouter.ts` з `import "server-only"`. Змінна — `OPENROUTER_API_KEY`, без `NEXT_PUBLIC_`.
- Ланцюжок моделей (лише `:free`): `nvidia/nemotron-3.5-super-vl:free` → `google/gemma-4-31b-it:free` →
  `google/gemma-4-26b-a4b-it:free`; суддя живого eval — `google/gemma-4-31b-it:free` (інша родина, ніж перша модель).
  Оновлено 2026-11-15 у PR функції (людина погодила): у наборі курсу Nemotron стоїть третьою, але відповідь помічника
  — суто структура, а Nemotron — єдина з трьох зі строгою схемою (`structured_outputs`), тож менше відповідей не за
  схемою (для людини це AC-ASSIST-09); golden cases PM — англійською, тож брак української в її картці не заважає.
  Живий eval показує, яка модель відповіла на кожен кейс; якщо Nemotron провалиться — повертаємо порядок набору.
  Суддя має запасних (Gemma 26B, Nemotron): 15.11 постачальник Gemma 31B відповів 429 при вільному ліміті акаунта, і без
  запасних прогін зупинявся (`evals/reports/README.md`). Рушій PDF
  `cloudflare-ai` з набору лишаємо в `models.ts` (безкоштовний; без нього OpenRouter узяв би платний `mistral-ocr`),
  хоча файлів зріз 4 не приймає.
- Таймаут виклику в функції — 30 с: дія передає явно `timeoutMs: 30_000` і `maxRetries: 0` (типові значення набору
  в `draft.ts` — 45 с і 1 повтор — не для нашого зрізу). Без повтору 30 с — межа всього очікування: один HTTP-запит,
  а fallback ланцюжка моделей OpenRouter робить на своєму боці всередині цього запиту (AC-ASSIST-09). Будь-який збій
  (`timeout`, `rate_limited`, `invalid_output`, `provider_error`) показує одне повідомлення AC-ASSIST-09, ручне
  додавання закриття працює далі.
- Людина в контурі: Server Action лише повертає пропозиції; запис — наявна `addClosure` для кожної пропозиції після
  перевірки адміністратором, з усіма правилами вимоги 04 (їх тримає база). Дія пропозицій спершу перевіряє
  `getClaims()` і роль так само, як `addClosure` і сторінка керування календарем (`manageAccess`), — до виклику
  моделі (AC-ASSIST-11), і довжину тексту (AC-ASSIST-10). Виклик моделі не йде через базу, тож RLS його не закриє:
  перевірка в дії — єдиний спосіб не витратити ліміт на чужий запит; запис і далі захищає база.
- Перевірка якості: 10 golden cases PM. Офлайн-реплей записаних відповідей (`MockLanguageModelV4`) — у `npm test`
  (CI); живий прогін — `npm run eval` вручну, зі звітом частки успіху за моделлю в `evals/reports/`.
- Порядок: цей ADR, залежності й файли набору (з прикладом набору «звернення → тікет», без AC ID у назвах тестів) —
  окремим PR; схему, промпт, golden cases PM, сторінку й AC ID — у PR функції (специфікацію злито в #78, план —
  `openspec/changes/impl-calendar-assistant/`). Код PDF набору (`FILE_TYPES`, `file` у `proposeDraft`) PR функції
  прибирає або не використовує: файлів зріз 4 не приймає.

## Розглянуті варіанти

- Claude Agent SDK у функції Vercel — ні: SDK запускає підпроцес Claude Code (~320–342 МБ), а пакет функції
  Vercel — до 250 МБ; до того ж тут потрібен один виклик моделі, а не агентний цикл.
- Пакет `openai` з `baseURL` OpenRouter або `@openrouter/sdk` — ні: немає валідації схемою з типізованими
  помилками й тестових моделей (`MockLanguageModelV4`) в одному API.
- `openrouter/free` (випадкова безкоштовна модель) — ні: результат golden cases не відтворюється.
- Платний ключ — ні: курс використовує безкоштовні моделі; перехід на платного провайдера — заміна однієї фабрики
  в `src/lib/ai/models.ts`.
- Розбір дат без моделі (регулярні вирази) — ні: вимога 05 — саме AI-функція, а відносні дати, «day first» і
  відмови на сторонні тексти вимагали б власного розбору природної мови.

## Наслідки

- Простіше: провайдера й модель міняємо в одному файлі; CI не залежить від мережі та ліміту.
- Складніше: безкоштовна модель може зникнути або впертися в ліміт — інтерфейс показує повідомлення AC-ASSIST-09,
  а адміністратор додає закриття вручну. Ланцюжок перевіряємо `npm run ai:models` перед роботою.
- Записи `tests/fixtures/golden/recorded.json` треба оновлювати (`RECORD=1 npm run eval`), коли змінюється
  промпт (`DRAFT_PROMPT_VERSION`) або схема.
- Ліміт 50 запитів/день ділять розробник (живий eval) і всі, хто користується помічником на проді, — за курсом
  (`docs/models.md` репо курсу) це й приймання PM на golden cases; у вимозі 05 цього немає, це наше планування:
  живий eval і приймання PM — на різні UTC-доби.
